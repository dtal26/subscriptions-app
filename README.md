# Мои подписки

Мобильное приложение для Android, которое помогает учитывать платные подписки на сервисы: показывает, сколько денег уходит на подписки в месяц и в год, когда будет ближайшее списание, и заранее напоминает о платежах.

Учебный проект по дисциплине «Технологии разработки мобильных приложений», БГТУ «ВОЕМЕХ» им. Д.Ф. Устинова.

\---

## Возможности

* **Регистрация и вход** с проверкой полей; пароли хранятся только в виде хэша (PBKDF2-HMAC-SHA256 с солью).
* **Список подписок** с общей суммой расходов в месяц и ближайшим списанием.
* **Добавление, редактирование и удаление** подписок: название, стоимость, периодичность (неделя / месяц / год), дата списания, категория.
* **Цветовая индикация срока** списания: красный — до 3 дней, оранжевый — до 7 дней, зелёный — больше 7 дней.
* **Статистика** расходов по категориям с анимированной кольцевой диаграммой, переключение «Месяц / Год».
* **Уведомления** о предстоящих списаниях (за 1, 3 или 7 дней), работают в фоне.
* **Курс валют ЦБ РФ** (доллар и евро), загружаемый из сети; последний курс сохраняется и доступен без интернета.
* Все данные хранятся **на устройстве** — приложение работает без интернета.

## Архитектура

Приложение построено по архитектуре **MVVM** (Model — View — ViewModel):

```
 View (экраны Compose)
        │  действия пользователя ↓      ↑ состояние экрана
 ViewModel (логика экрана, проверка полей, расчёты)
        │  запросы данных ↓             ↑ потоки Flow
 Repository (AuthRepository, SubscriptionRepository, CurrencyRepository)
        │
   ┌────┴─────────────┬──────────────────┐
 Room (SQLite)    DataStore        Retrofit (API ЦБ РФ)
 пользователи,    сессия,          курс доллара
 подписки         настройки, курс  и евро
```

* **View** — экраны на Jetpack Compose; только отображают состояние и передают действия пользователя.
* **ViewModel** — хранит состояние экрана, проверяет введённые данные, обращается к репозиториям.
* **Model** — репозитории и источники данных. Данные передаются через Kotlin Flow: при изменении записи в базе все экраны обновляются автоматически.

### Собственные UI-компоненты

* **`SubscriptionCard`** — карточка подписки с динамическим отображением: цвет таблички срока вычисляется по числу дней до списания и меняется с анимацией, полоска слева окрашена в цвет категории, при нажатии карточка плавно уменьшается.
* **`DonutChart`** — кольцевая диаграмма расходов, нарисованная вручную на `Canvas` (без сторонних библиотек), с анимацией «разворачивания» кольца.

### Сетевое взаимодействие

Курс доллара и евро загружается по REST API:

```
GET https://www.cbr-xml-daily.ru/daily\_json.js
```

Ответ в формате JSON преобразуется в объекты Kotlin с помощью Retrofit и Gson. Последний загруженный курс сохраняется в DataStore; при отсутствии интернета показывается сохранённый курс с пометкой «нет связи».

## Установка и запуск

### Требования

* [Android Studio](https://developer.android.com/studio) (последняя стабильная версия);
* эмулятор Android или телефон с Android 8.0 и выше;
* интернет при первой сборке (Gradle скачивает библиотеки).

### Запуск из исходного кода

1. Клонируйте репозиторий:

```bash
   git clone https://github.com/<имя-пользователя>/<название-репозитория>.git
   ```

   или скачайте архив: **Code → Download ZIP** и распакуйте его в папку, путь к которой содержит только латинские буквы и не содержит пробелов.

2. Откройте Android Studio → **Open** → выберите папку проекта.
3. Дождитесь окончания синхронизации Gradle (при первом открытии может занять несколько минут).
4. Создайте эмулятор: **Device Manager → + → Create Virtual Device** (например, Pixel 7) или подключите телефон с включённой отладкой по USB.
5. Выберите устройство и нажмите **Run ▶**.

### Первое использование

1. Зарегистрируйтесь: имя, email, пароль не короче 8 символов.
2. Разрешите приложению отправлять уведомления (Android 13+).
3. Добавьте подписки кнопкой **«+»** или нажмите **«Заполнить примерами»** на пустом главном экране.
4. Проверить уведомления можно сразу: **Настройки → Проверить напоминания**.

## Сборка release-версии с обфускацией

В release-сборке включены обфускация и оптимизация кода R8, а также удаление неиспользуемых ресурсов (`app/build.gradle.kts`):

```kotlin
buildTypes {
    release {
        // в AGP 9.3+ блок optimization заменяет isMinifyEnabled и isShrinkResources
        optimization {
            enable = true
        }
        signingConfig = signingConfigs.getByName("debug")
    }
}
```

Сборка APK:

1. **View → Tool Windows → Build Variants** → для модуля `app` выберите **release**.
2. **Build → Generate App Bundles or APKs → Generate APKs**.
3. Готовый файл: `app/build/outputs/apk/release/app-release.apk`.

Результат обфускации можно проверить через **Build → Analyze APK** (классы приложения переименованы в короткие имена). Таблица соответствия имён сохраняется в `app/build/outputs/mapping/release/mapping.txt` и в репозиторий не добавляется.

> Release-сборка подписана отладочным ключом — этого достаточно для установки на эмулятор и демонстрации. Для публикации в магазине приложений нужен собственный ключ.

## Тестирование

Модульные тесты (21 тест) проверяют проверку полей, хэширование паролей и расчёты сроков и сумм:

|Класс|Что проверяет|
|-|-|
|`ValidatorsTest`|формат email, длина и совпадение паролей, имя, стоимость|
|`SubscriptionUtilsTest`|склонение «день/дня/дней», текст срока, цвет срочности, месячная стоимость, перенос прошедшей даты списания, формат суммы|
|`PasswordHasherTest`|проверка правильного и неправильного пароля, влияние соли, отсутствие пароля в хэше|

Запуск из терминала в папке проекта:

```bash
./gradlew testDebugUnitTest      # macOS / Linux
.\\gradlew testDebugUnitTest      # Windows
```

Отчёт с результатами: `app/build/reports/tests/testDebugUnitTest/index.html`.
